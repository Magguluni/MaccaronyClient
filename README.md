# MaccaronyClient

MaccaronyClient ist ein Minecraft-Launcher für Windows von Maccarony (Minecraft: Magguluni). Er bündelt Bibliothek und Instanzen, Mods, Resource Packs, Shader, Modpacks, Plugins, Skins, Capes und Freunde an einem Ort.

Website: https://magguluni.github.io/MaccaronyClient/

## Neue Version veröffentlichen

1. Erstelle ein neues [Release](https://github.com/Magguluni/MaccaronyClient/releases/new).
2. Hänge die Setup-Datei als Asset an. Der Dateiname muss genau `MaccaronyClient-Setup.exe` sein.

Die Download-Buttons der Website zeigen auf:

https://github.com/Magguluni/MaccaronyClient/releases/latest/download/MaccaronyClient-Setup.exe

Damit lädt der Button immer die Datei aus dem neuesten Release.
